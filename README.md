# SECTOR // ARENA

GitHub Pages에 바로 올릴 수 있는 **2D 탑다운 온라인 전투** 웹 게임입니다. 서버 설치가 필요 없습니다.

## 지금 들어 있는 것

- 한 화면에 전체가 보이는 고정형 전술 아레나
- 체력 **100**
- **총**: 공격력 10, 1초마다 발사
- **검**: 가까이서 공격력 20, 1초마다 휘두르기
- 지정 접근코드 `QPDF-JWOF-NIBP`로 온라인 대전 (공개 MQTT 브로커 사용)
- 태블릿: 왼쪽 스틱 이동, 오른쪽 스틱 조준, 총/검 버튼

## 조작

| | PC | 태블릿 |
|---|---|---|
| 이동 | WASD | 왼쪽 스틱 |
| 조준 | 마우스 | 오른쪽 스틱 |
| 총 | 좌클릭 | 총 버튼 |
| 검 | 우클릭 / 스페이스 | 검 버튼 |

## 로컬에서 열기

브라우저가 모듈/네트워크를 막지 않도록 간단한 웹 서버로 여세요.

```bash
npx --yes serve .
```

또는 VS Code Live Server.

## GitHub Pages에 올리기

1. GitHub에 새 저장소를 만듭니다.
2. 이 폴더의 파일(`index.html`, `css/`, `js/`, `manifest.json`, `.nojekyll`)을 올립니다.
3. 저장소 **Settings → Pages**
4. Source를 **Deploy from a branch**
5. Branch를 `main` (또는 `master`), folder를 `/ (root)` 로 저장
6. 잠시 후 `https://아이디.github.io/저장소이름/` 에서 실행됩니다.

새 방을 만들지 않습니다. 두 기기에서 닉네임을 입력하고 접근코드 `QPDF-JWOF-NIBP`를 넣으면 같은 전장으로 접속합니다.

## 참고

온라인은 프로토타입용 공개 MQTT 브로커를 씁니다. 암호는 없고, 지정 접근코드를 아는 사람이 전장에 접속할 수 있습니다.
